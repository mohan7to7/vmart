# VMart

Enterprise-style e-commerce platform built with Java/Spring Boot and Angular.

## Stack
- Java 25
- Spring Boot 4
- Maven
- PostgreSQL
- Angular 22
- TypeScript
- Docker / Docker Compose

Future releases will add Redis, Kafka, advanced search, and AWS.

## Structure
```text
vmart/
├── backend/
├── frontend/
├── docs/
├── .env.example
├── .gitignore
├── docker-compose.yml
└── README.md
```

## Roadmap
- v0.1.0 - Project foundation
- v1.0.0 - Core e-commerce
- v2.0.0 - Redis and commerce enhancements
- v3.0.0 - Kafka/event-driven architecture
- v4.0.0 - Advanced search and performance
- v5.0.0 - AWS/cloud production architecture
